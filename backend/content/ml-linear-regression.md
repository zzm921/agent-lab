## 概述

线性回归是用一条直线拟合「只有一个输入特征」的训练数据、从而对新输入做预测的最简单回归模型，也是理解多元回归、神经网络等一切复杂模型的地基。核心公式：

```
f(x) = wx + b
```

w 是权重（斜率）：决定直线「倾斜得多厉害」；b 是偏置（截距）：决定直线在 y 轴上的整体高低。不同 (w, b) 组合对应不同直线，训练就是挑出「整体误差最小」的那一条。

**直觉**：把训练数据画在坐标系里，每个样本是一个点。线性回归就是在「找一把最合适的直尺」——让这把直尺尽可能同时靠近所有点。

## 为什么需要代价函数

光看直线「像不像」太主观，需要把「拟合程度」量化成一个数值。代价函数 J(w, b) 把所有样本的预测误差汇总成一个非负数，J 越小拟合越好：

```
J(w, b) = (1 / 2m) · Σᵢ₌₁ᵐ ( f(x⁽ⁱ⁾) - y⁽ⁱ⁾ )²
```

**每一处设计都有明确理由**：

| 设计 | 理由 |
|---|---|
| 取误差 (f − y) | 直接衡量预测与真实的偏离程度 |
| 平方 | ① 避免正负抵消（+5 与 −5 不能算完美）② 放大较大误差，促使模型优先修正离谱样本 ③ 处处可导、整体凸，方便梯度下降稳定求解 |
| 除以 m | 取平均，J 与样本量无关，便于跨数据集比较 |
| 除以 2 | 纯粹为求导便利：平方项求导带出系数 2，恰好抵消 |

注意：除以 2 只是把函数缩放一半，**不改变最小值对应的 (w, b)**，不要给它编造「平均」之类的含义。

**直觉**：J 就像「全班考试的平均错题数」——错得越多平均分越低，代价函数把「糟糕程度」压缩成一个数字。

## 多元线性回归与向量化

当预测不只依赖一个特征时，把多个特征分别乘以各自权重再相加（并加偏置）：

```
f(x) = w₁x₁ + w₂x₂ + ... + wₙxₙ + b
```

**向量化写法**：w = [w₁, ..., wₙ]，x = [x₁, ..., xₙ]，则 f(x) = w · x + b（点积 = 对应分量相乘再求和）。

每个权重 wⱼ 的含义是：**在其他特征保持不变时，特征 j 每增加 1 个单位，预测值平均变化 wⱼ**——不能脱离其他特征孤立解读。

**实例**：f(x) = 0.1x₁ + 4x₂ + 10（x₁=面积、x₂=卧室数），对 2000 平方英尺、3 卧室：f = 200 + 12 + 10 = 222 万，其中面积贡献 200、卧室数贡献 12、基础价 10。

## 多项式回归：让线性模型拟合曲线

真实数据很少是笔直的线性关系。把特征改造成多项式形式：

```
原模型： f(x) = w₁x + b
多项式： f(x) = w₁x + w₂x² + w₃x³ + b
```

**关键洞察**：把 x² 看作一个全新特征，原式就是多元线性回归的形式。所以**多项式回归的本质 = 特征工程 + 线性回归**——模型结构本身没有变复杂。

⚠️ 引入多项式特征后几乎必须配合**特征缩放**：x 取上百时 x²、x³ 比 x 大几个数量级，梯度下降在数值小的特征上步子过大、在数值大的特征上步子过小，收敛极慢甚至震荡。

## 收益与边界

- 单变量 → 多元 → 多项式的递进路径，是理解所有监督模型的通用骨架；
- 代价函数的「为什么平方、为什么除以 2m」是面试与推导高频点；
- 权重解读必须结合单位与「其他特征不变」的前提；
- 边界：线性回归预测**连续数值**，不能直接用于分类；特征越多灵活性越高、过拟合风险也越大。

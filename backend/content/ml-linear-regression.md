## 单变量线性回归

**定义**

单变量线性回归是用一条直线拟合"只有一个输入特征"的训练数据，从而对新输入做出预测的最简单的回归模型，也是理解更多复杂模型（多元回归、神经网络）的地基。

**模型公式**

```
f(x) = wx + b
```

**符号表**

| 符号 | 含义 |
|---|---|
| x | 输入特征（自变量），例如房屋面积 |
| w | 权重（斜率），表示 x 每增加 1 个单位，预测值 f(x) 变化 w 个单位 |
| b | 偏置（截距），表示 x = 0 时直线的取值，即直线与 y 轴的交点 |
| f(x) | 模型的预测值（因变量），例如预测房价 |

**为什么（几何意义）**

在二维坐标系中，f(x) = wx + b 就是一条直线，w 与 b 各有明确的几何角色：

- **w 是斜率**：w > 0 时直线向右上方倾斜，x 越大预测值越大；w < 0 时直线向右下方倾斜；|w| 越大直线越陡峭。直观地说，w 决定这条线"倾斜得多厉害"。
- **b 是截距**：它决定直线在 y 轴上的整体高度。b 越大，整条直线平行上移；b 越小则平行下移。

x 是我们用来做预测的信息（如面积），f(x) 是模型给出的答案（如房价）。模型本身只是一条直线，真正的问题是：**选哪一条？** 也就是 w、b 各取什么值。不同的 (w, b) 组合对应完全不同的直线，我们想要的是最贴合训练数据的那一条。

**直觉**

把训练数据画在坐标系里，每个样本是一个点。线性回归就是在"找一把最合适的直尺"——让这把直尺尽可能地同时靠近所有点。

**实例**

假设训练集只有两个样本：

- 样本 1：面积 1.2（千平方英尺）→ 价格 30（万）
- 样本 2：面积 2.0（千平方英尺）→ 价格 45（万）

不同的 (w, b) 对应不同的直线，拟合效果也不同：

- 取 w = 20、b = 6：f(1.2) = 20×1.2 + 6 = 30，刚好过样本 1；但 f(2.0) = 20×2.0 + 6 = 46，比真实的 45 高了 1，直线偏陡。
- 取 w = 25、b = 0：f(1.2) = 30，过样本 1；但 f(2.0) = 50，比真实的 45 高 5，偏离更大。
- 取 w = 18.75、b = 7.5：f(1.2) = 18.75×1.2 + 7.5 = 30，f(2.0) = 18.75×2.0 + 7.5 = 45，完美穿过两个样本。

可以看出：w 决定直线的倾斜程度，b 决定直线上下平移，两者共同决定直线位置。训练的目标就是在 (w, b) 的所有取值中挑出"整体误差最小"的那一组。

**常见误区/注意点**

- w 与 b 都很重要：w 管"方向与陡峭"，b 管"整体高低"，两者都要训练，不能只调其中一个。
- x 的单位会影响 w 的数值含义：面积用"千平方英尺"还是"平方英尺"，对应的最优 w 完全不同，解读权重时必须结合单位。
- 单变量只有一个特征，但它的整套思想（代价函数、梯度下降）可以原样推广到多特征情形。

## 代价函数（Cost Function）

**定义**

代价函数 J(w, b) 用一个数值衡量"当前直线对训练数据的拟合程度"：它把所有样本的预测误差汇总成一个非负的数，J 越小，拟合越好。

**公式**

```
J(w, b) = (1 / 2m) · Σᵢ₌₁ᵐ ( f(x⁽ⁱ⁾) - y⁽ⁱ⁾ )²
```

其中 f(x⁽ⁱ⁾) = wx⁽ⁱ⁾ + b。

**符号表**

| 符号             | 含义                                      |
| -------------- | --------------------------------------- |
| J(w, b)        | 代价函数，是关于参数 w、b 的函数；不同的 (w, b) 对应不同的 J 值 |
| m              | 训练样本的总个数                                |
| i              | 样本编号，i = 1, 2, ..., m                   |
| x⁽ⁱ⁾           | 第 i 个样本的特征值（如面积）                        |
| y⁽ⁱ⁾           | 第 i 个样本的真实标签值（如真实价格）                    |
| f(x⁽ⁱ⁾)        | 模型对第 i 个样本的预测值                          |
| f(x⁽ⁱ⁾) - y⁽ⁱ⁾ | 第 i 个样本的误差（残差）                          |
| Σᵢ₌₁ᵐ          | 对 m 个样本的误差平方求和                          |
| 1/2m           | 平均化系数与求导便利系数的组合                         |

**为什么（推导/设计动机）**

这个公式的每一处设计都有一个明确理由：

1. **为什么取"误差"（f - y）**：误差直接衡量预测与真实的偏离程度。误差为 0 表示该样本被完全预测正确。
2. **为什么"平方"**：
   - **避免正负抵消**：误差有正有负，若直接求和，+5 和 -5 会抵消成 0，让人误以为拟合完美，实际却错得离谱。平方后每一项恒为非负，不再抵消。
   - **放大较大误差**：平方会放大偏离。误差 1 与 3 的平方分别是 1 和 9，差距从 3 倍变成 9 倍，促使模型优先修正那些错得离谱的样本。
   - **可导且形状简单**：平方函数处处可导，且整体是凸函数，方便后续用梯度下降稳定求解。
3. **为什么"除以 m"（取平均）**：不加平均时，J 是所有误差平方的总和，样本越多总和天然越大。除以 m 后，J 表示"平均每个样本的误差平方"，与样本量无关，便于在不同规模的数据集上比较模型好坏。
4. **为什么"除以 2"（求导便利）**：纯粹为了求导方便。平方项求导会带出系数 2，除以 2 恰好与之抵消：

```
∂J/∂w = (1/2m) · Σᵢ₌₁ᵐ 2·(f(x⁽ⁱ⁾) - y⁽ⁱ⁾)·x⁽ⁱ⁾
      = (1/m) · Σᵢ₌₁ᵐ (f(x⁽ⁱ⁾) - y⁽ⁱ⁾)·x⁽ⁱ⁾
```

求导后的表达式变得干净简洁。除以 2 只是把整个函数缩放一半，**不会改变最小值对应的 (w, b)**，所以对求解没有影响。

**实例（逐步手算）**

训练集 3 个样本：(x, y) = (1, 1)、(2, 2)、(3, 3)。当前模型为 f(x) = 0.5x + 1。

- 样本 1：x = 1 → f(1) = 0.5×1 + 1 = 1.5，误差 = 1.5 − 1 = 0.5，平方 = 0.25
- 样本 2：x = 2 → f(2) = 0.5×2 + 1 = 2.0，误差 = 2.0 − 2 = 0，平方 = 0
- 样本 3：x = 3 → f(3) = 0.5×3 + 1 = 2.5，误差 = 2.5 − 3 = −0.5，平方 = 0.25

求和：0.25 + 0 + 0.25 = 0.5
除以 2m = 2×3 = 6：J = 0.5 / 6 = 1/12 ≈ 0.083

方向感对比（感受"更小/更大"意味着什么）：

- 取 w = 1、b = 0（即 f(x) = x）：三个样本误差全为 0，J = 0，比 0.083 更小——因为这条直线恰好完美穿过所有点。
- 取 w = 2、b = 0（即 f(x) = 2x）：误差为 1、2、3，平方和为 1 + 4 + 9 = 14，J = 14/6 ≈ 2.33，比 0.083 大得多。

结论：J 为"参数好不好"提供了数值刻度，训练就是在 (w, b) 空间中寻找 J 最小的那一点。

**直觉**

J 就像"全班考试的平均错题数"：直线是标准答案，每个点是一个学生，错得越多平均分越低。代价函数把这个"糟糕程度"压缩成一个数字，数字越小，直线越贴近数据。

**常见误区/注意点**

- J 是 w、b 的函数，不是 x 的函数；x、y 是已知数据，真正要优化的是参数 w、b。
- 平方误差是线性回归的标准选择，但"平方"不是万能的，分类问题要用别的代价函数。
- 误差写成 (预测 − 真实) 或 (真实 − 预测) 都可以，平方后符号无关。
- 除以 2 只是求导便利，不要给它编造"平均"之类的实际含义；"取平均"是除以 m 的职责。

## 多元线性回归（多特征）

**定义**

当预测不只依赖一个特征时，把多个特征分别乘以各自的权重再相加（并加上偏置），就得到多元线性回归。它把"一条直线"推广为"一张超平面"。

**模型公式**

```
f(x) = w₁x₁ + w₂x₂ + ... + wₙxₙ + b
```

**符号表**

| 符号 | 含义 |
|---|---|
| n | 特征个数 |
| x₁, x₂, ..., xₙ | 第 1 到第 n 个特征（如面积、卧室数、房龄…） |
| w₁, w₂, ..., wₙ | 每个特征对应的权重，衡量该特征对预测的贡献大小 |
| b | 偏置 |
| f(x) | 预测值 |

**向量化写法**

把 n 个权重组成向量 w = [w₁, w₂, ..., wₙ]，n 个特征组成向量 x = [x₁, x₂, ..., xₙ]，则：

```
f(x) = w · x + b
```

其中 w · x 是点积（内积）：对应分量相乘再求和，即 w₁x₁ + w₂x₂ + ... + wₙxₙ。

向量化的意义：符号更简洁，且点积恰好对应"每个特征按权重加权求和"这一操作，便于统一、高效地计算。

**为什么（设计动机）**

单个特征能解释的变化有限。例如房价：面积大的房子不一定贵，还要看卧室数、地段、房龄。多特征让模型能同时利用多条信息。每个权重 wⱼ 的含义是：**在其他特征保持不变时，特征 j 每增加 1 个单位，预测值平均变化 wⱼ**。

**实例**

预测房价，两个特征：x₁ = 面积（平方英尺）、x₂ = 卧室数。假设模型参数为 w₁ = 0.1、w₂ = 4、b = 10，即 f(x) = 0.1x₁ + 4x₂ + 10。

对一套面积 2000 平方英尺、3 卧室的房子：

```
f = 0.1×2000 + 4×3 + 10
  = 200 + 12 + 10
  = 222（万）
```

即模型预测这套房价值 222 万，其中面积贡献 200 万、卧室数贡献 12 万、基础价 10 万。

向量化验证：w = [0.1, 4]，x = [2000, 3]，w·x = 0.1×2000 + 4×3 = 212，再加 b = 10 得 222，与逐项计算一致。

**常见误区/注意点**

- 多元模型的代价函数形式与单变量完全一样，只是其中的 f(x) 换成多特征形式。
- 各特征数值范围差异很大（面积上千、卧室数不到 10），通常需要特征缩放。
- 权重 wⱼ 的含义只有在"其他特征不变"时才成立，不能脱离其他特征孤立解读。

## 特征工程与多项式回归

**定义**

特征工程是根据对问题的理解，从已有特征构造新特征的过程；多项式回归是把特征改造成多项式形式，让"线性模型"也能表达非线性关系。

**为什么（设计动机）**

真实数据很少是笔直的线性关系。例如房价：小面积阶段价格随面积几乎线性上涨，但面积继续增大时涨幅放缓甚至趋平。用直线硬拟合，要么中间偏、要么两端偏，误差很大。此时模型需要"曲线"能力。

**多项式回归模型**

```
原模型： f(x) = w₁x + b
多项式： f(x) = w₁x + w₂x² + w₃x³ + b
```

**关键洞察：x² 是新特征**

把 x² 看作一个全新的特征（记作新特征 = x²），原式可重写为：

```
f(x) = w₁x + w₂·(新特征) + w₃·(新特征²) + b
```

这正是多元线性回归的形式。也就是说：**多项式回归的本质是"特征工程 + 线性回归"**——我们只是把 x²、x³ 当作新特征喂给同一个线性模型，模型结构本身没有变复杂。这也说明，通过特征工程，"线性模型"也能拟合出曲线。

**实例**

用二次多项式 f(x) = w₁x + w₂x² 拟合"先涨后平"的数据：w₁ > 0 提供上升的主体趋势，w₂ < 0 提供向下的弯曲，两者叠加即为开口向下的抛物线，正好贴合"先涨后平"的变化形态。训练时 w₁、w₂ 由代价函数配合梯度下降自动确定，不需要手工指定。

**为什么必须做特征缩放**

当 x 数值较大时，x² 会急剧放大数值差异。例如 x = 50 时 x² = 2500，x = 100 时 x² = 10000：特征本身只有 2 倍差距，平方后变成 4 倍。若 x 取值上百，x²、x³ 的数值范围会比 x 大几个数量级，导致梯度下降在数值小的特征上步子过大、在数值大的特征上步子过小，收敛极慢甚至震荡。因此引入多项式特征后，几乎必须配合特征缩放（把各特征缩放到相近范围）。

**常见误区/注意点**

- 阶数不是越高越好：高次多项式能穿过更多点，但容易剧烈震荡、过拟合。
- 特征缩放与多项式特征几乎总是成对出现：只加多项式不缩放，优化会非常慢。
- 特征工程依赖对问题的理解，不是机械地堆砌各种变换。

## 易错点与要点

| 要点          | 说明                                                    |
| ----------- | ----------------------------------------------------- |
| 回归 vs 分类    | 线性回归预测的是**连续数值**（如房价、温度），不能直接用于分类（如"是/否"），分类要用逻辑回归等模型 |
| 代价函数选择      | 线性回归的标准代价函数是平方误差；分类问题必须换用其他代价函数，否则梯度下降可能表现很差          |
| 特征越多不一定越好   | 特征增加会提升模型灵活性，但也增大过拟合风险，需要配合正则化或模型评估手段                 |
| 除以 2m 的两个目的 | 除以 m 是取平均、使代价与样本量无关；除以 2 是为求导消系数。两者目的不同，缺一不可          |
| 特征缩放        | 各特征数值范围差异大时，梯度下降收敛慢甚至震荡，需要先做特征缩放                      |
| 多项式回归的本质    | 多项式回归 = 特征工程（x²、x³ 作为新特征）+ 线性回归，模型结构仍是线性的             |
| 单位的陷阱       | 权重的数值大小依赖特征单位，跨数据集比较权重前需先统一单位或做缩放                     |

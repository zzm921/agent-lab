## 概述

机器学习是让计算机**在没有被显式编程的情况下**，从数据中自动学习规律、并据此做出预测或决策的学科。它既是 AI 的核心分支，也是理解神经网络、大模型等一切前沿技术的地基。

前置数学基础：
- 微积分（单变量、多变量）
- 线性代数（矩阵、向量、点积、矩阵乘法）
- 概率论（随机变量、概率分布、期望、方差）

建议可以看3Blue1Brown的相关数学基础视频。帮助在学习前快速了解相关知识。在心中形成相关知识轮库，后续学习计算推导相关内容可再次回顾加深映像。


先建立一张全景地图：

```
人工智能 AI（最外层）
├── 机器学习 ML：让机器从数据中学习规律
│   └── 深度学习 DL：用多层神经网络实现的机器学习
└── 其他 AI 方法：专家系统、搜索、规则推理等
```

一句话概括三者关系：**深度学习 ⊂ 机器学习 ⊂ 人工智能**。

## 与传统编程的本质区别

| | 传统编程 | 机器学习 |
|---|---|---|
| 输入 | 规则（程序）+ 数据 | 数据 + 标签 |
| 过程 | 计算机执行规则 | 学习算法寻找规律 |
| 输出 | 答案 | 模型（规律） |

```
传统编程：
  规则（程序） + 数据  →  计算机执行  →  输出答案

机器学习：
  数据 + 标签        →  学习算法      →  输出模型（规律）
                                           ↓
                                    新数据 + 模型 → 预测结果
```

**直觉**：传统编程像「抄作业前先背答案」，机器学习像「做完 1000 道题后自己总结出解题套路」。

## 机器学习的三个适用条件（缺一不可）

1. **有数据**：存在足够多、有代表性的历史数据；
2. **有规律**：数据背后存在可学习的模式；
3. **无法手写规则**：规律太复杂、太模糊，人类写不出明确判断规则。

## 两大范式

### 监督学习（Supervised Learning）

数据由「输入 x — 输出 y」的成对样本组成（带标签的「问题-答案」对），算法学习从 x 到 y 的映射 f，使 f(x) 尽量接近 y。

| 任务 | 预测目标 | 输出形态 | 典型例子 |
|---|---|---|---|
| 回归（Regression） | 连续数值 | 任意实数区间 | 房价、气温、体重 |
| 分类（Classification） | 离散类别 | 有限个类别标签 | 猫/狗、垃圾邮件、癌症有无 |

判断标准不是「输出是不是数字」，而是「数字是否代表一个连续量」：识别图片中的「数字 5」是分类（类别），预测房价 380 万才是回归（连续值）。

**直觉**：监督学习像「带答案的练习题」——题目是 x，答案是 y，机器练得越多、猜得越准。

### 无监督学习（Unsupervised Learning）

数据只包含输入 x、没有输出 y，算法需要在数据中**自行发现结构、模式或规律**。

| 维度 | 监督学习 | 无监督学习 |
|---|---|---|
| 数据 | 有标签 (x, y) | 无标签 (x) |
| 目标 | 预测 y | 发现数据内部的结构/模式 |
| 典型任务 | 回归、分类 | 聚类、异常检测、降维 |
| 评价方式 | 与真实标签对比 | 没有标准答案，靠业务意义评估 |

**直觉**：监督学习是「带着答案清单去考试」，无监督学习是「自己发现考卷里有几道题属于同一题型」。

## 统一术语与符号

**术语一句话串联**：训练集里有 **m 个样本**，每个样本用**特征**（x）描述，带着**标签**（y）；学习算法从中找出一个**模型** f，模型的形状由**参数** w、b 决定；训练过程就是不断调整参数、让预测尽量接近标签。

| 术语 | 英文 | 房价预测示例 |
|---|---|---|
| 训练集 | Training Set | 1000 套房子的历史记录 |
| 样本 | Example | 1 套房子 = 一个样本 |
| 特征 | Feature (x) | 面积 80 ㎡、卧室数（可多个） |
| 标签 | Label (y) | 成交价 250 万 |
| 模型 | Model | 「面积 → 房价」的预测函数 f |
| 参数 | Parameter (w, b) | 面积每 +1 ㎡ 房价涨 w 万元 |

**符号约定**：m = 样本个数；x⁽ⁱ⁾ = 第 i 个样本的特征；y⁽ⁱ⁾ = 第 i 个样本的标签；f(x) = 模型预测；w = 权重（斜率）；b = 偏置（截距）。注意 x⁽ⁱ⁾ 的上标是**样本编号**（不是幂次）。

## 两条主线（全课程框架）

- **主线一：如何定义模型 f**。最简单的入门形式是线性模型 f(x) = w·x + b；
- **主线二：如何找到最优参数 w, b**。训练就是调整参数使预测接近标签——后续「代价函数 + 梯度下降」系统解决这个问题。

```
循环 直到误差不再下降：
    对 训练集中的每个样本:
        预测 = 模型(样本特征, 当前参数 w, b)
        误差 = 预测 与 标签 的差距
    更新参数 w, b，使总体误差变小
输出: 训练好的模型（含最优参数 w, b）
```

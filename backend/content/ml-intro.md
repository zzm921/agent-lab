## 什么是机器学习

**定义**：机器学习是让计算机在没有被显式编程的情况下，从数据中自动学习规律、并据此做出预测或决策的学科。

**机器学习在 AI 中的位置（包含关系）**

```
人工智能 AI（最外层）
├── 机器学习 ML：让机器从数据中学习规律
│   └── 深度学习 DL：用多层神经网络实现的机器学习
└── 其他 AI 方法：专家系统、搜索、规则推理等
```

一句话概括三者的关系：**深度学习 ⊂ 机器学习 ⊂ 人工智能**。深度学习只是实现机器学习的一种方式（多层神经网络），机器学习又只是实现人工智能的一条路径。

**机器学习与传统编程的本质区别**

传统编程是「人写规则，机器执行」；机器学习是「人给数据，机器自己找规律，生成模型」：

```
传统编程：
  规则（程序） + 数据  →  计算机执行  →  输出答案

机器学习：
  数据 + 标签        →  学习算法      →  输出模型（规律）
                                           ↓
                                    新数据 + 模型 → 预测结果
```

**机器学习的三个适用条件**（缺一不可）：
1. **有数据**：存在足够多、有代表性的历史数据（如过去 1000 套房子的成交记录）。
2. **有规律**：数据背后存在可学习的模式（房价与面积、地段相关）。
3. **无法手写规则**：规律太复杂、太模糊，人类写不出明确的判断规则（例如「判断照片是不是猫」）。

**直觉**：传统编程像「抄作业前先背答案」，机器学习像「做完 1000 道题后自己总结出解题套路」。

**实例**：要判断一封邮件是否为垃圾邮件。传统方法需要人工编写几百条规则（如「包含『中奖』算垃圾」），穷举不尽；机器学习只需要收集 1 万封已标注的邮件，交给算法自动学会判断模式，还能持续适应新的垃圾邮件变种。

**常见误区/注意点**：
- 误区一：把「机器学习」与「人工智能」划等号。机器学习只是 AI 的一个子集。
- 误区二：以为机器学习是「万能钥匙」。没有数据、没有规律或规律可手写时，都不适合用机器学习。
- 误区三：混淆「训练」和「预测」。训练是学习阶段（拿数据生成模型），预测是使用阶段（拿新数据算答案）。

## 机器学习能做什么 / 不能做什么

**定义**：在动手学算法之前，先建立合理的预期——机器学习适合解决哪类问题、又对哪些问题无能为力。

**能做什么**：
- 从数据中找规律并预测：房价、气温、销售额等数值预测。
- 自动分类：图像识别（猫/狗）、垃圾邮件过滤、疾病诊断。
- 发现数据中的结构：用户分群、新闻聚类、异常告警。
- 自动完成重复性判断任务，且规律复杂到无法人工写规则。

**不能做什么**（当前阶段）：
- 不能「无中生有」：数据里没有的信息，模型无法凭空给出。
- 不能保证绝对正确：模型只能给出统计意义上的合理预测。
- 不能解释因果关系：学到的相关性 ≠ 因果性（冰淇淋销量与溺水人数相关，但前者并不导致后者）。
- 数据有偏时，模型会继承并放大偏见（如只用男性简历训练出的招聘模型会歧视女性）。

**常见误区/注意点**：
- 把「预测准确率 100%」当作目标：现实中数据总有噪声，追求完美通常意味着过拟合。
- 以为「数据越多越好」：还要保证数据质量（正确、无偏、有代表性）。
- 混淆「相关」与「因果」：模型学到的模式只能说明相关性。

## 监督学习（Supervised Learning）

**定义**：数据由「输入 x — 输出 y」的成对样本组成（即带标签的「问题-答案」对），算法学习从 x 到 y 的映射函数 f，使 f(x) 尽量接近 y。

**两类典型任务对比**

| 任务                 | 预测目标 | 输出形态    | 典型例子          |
| ------------------ | ---- | ------- | ------------- |
| 回归（Regression）     | 连续数值 | 任意实数区间  | 房价、气温、体重      |
| 分类（Classification） | 离散类别 | 有限个类别标签 | 猫/狗、垃圾邮件、癌症有无 |

**「离散 vs 连续」的含义**：
- **连续（连续值）**：输出是数轴上的一段区间，可无限细分。例如房价可以在 50 万到 1500 万之间取任意值，你关心的不是「是不是房」而是「值多少钱」。
- **离散（类别）**：输出只能属于有限的几个集合。例如「猫 / 狗」只有两类，「有无癌症」只有两类，判断结果是一个标签而不是一个数字。

**回归实例（带具体数字）**：训练集含 1000 套房子，每套记录特征（面积 80 ㎡、卧室 2 间、地段评分 7.5），标签是成交价（如 250 万）。模型学出 f(x) 后，对一套新房子（面积 120 ㎡、3 间卧室、地段 8.0）预测出「约 380 万」——这是一个连续数值，属于回归。同理：根据历史体温数据预测明天体温 36.8℃ 也是回归。

**分类实例**：给算法 1000 张带「猫 / 狗」标签的图片，它学会后判断新图片是「猫」还是「狗」；给算法 1 万封已标注的邮件，它判断新邮件「是 / 不是」垃圾邮件——输出的都是类别标签，属于分类。

**为什么监督学习可行**：因为有「标准答案」（标签）可以当参照物。算法反复拿自己的预测与真实标签比较，误差越大就调整越多，像学生对照参考答案订正作业，逐步逼近正确答案。

**直觉**：监督学习像「带答案的练习题」——题目是 x，答案是 y，机器练得越多、猜得越准。

**常见误区/注意点**：
- 误区一：以为「分类问题的答案一定只有两类」。多分类很常见（如识别 10 种动物），关键是输出仍是有限类别，而非连续值。
- 误区二：把「预测的是数字」当成回归的判断标准。判断标准是「数字是否代表一个连续量」。识别图片中的「数字 5」是分类（类别），预测房价 380 万才是回归（连续值）。
- 误区三：分类中的类别个数虽然有限，但二分类（0/1）是最基础的形式，多分类可看作它的推广。

## 无监督学习（Unsupervised Learning）

**定义**：数据只包含输入 x、没有输出 y（没有「正确答案」），算法需要在数据中自行发现结构、模式或规律。

**与监督学习的逐维度对比**

| 维度 | 监督学习 | 无监督学习 |
|---|---|---|
| 数据 | 有标签 (x, y) | 无标签 (x) |
| 目标 | 预测 y（学习 x→y 映射） | 发现数据内部的结构/模式 |
| 典型任务 | 回归、分类 | 聚类、异常检测、降维 |
| 评价方式 | 与真实标签对比，误差可量化 | 没有标准答案，靠业务意义评估 |
| 难度 | 相对明确（目标清晰） | 相对困难（目标开放） |

**三大典型任务**

1. **聚类（Clustering）**：把相似的样本自动分到同一个簇（cluster），簇内相似、簇间不同。它不知道簇的标签是什么，只负责「物以类聚」。
2. **异常检测（Anomaly Detection）**：先学习「正常数据长什么样」，再找出与正常模式显著不同的样本（异常点）。
3. **降维（Dimensionality Reduction）**：在保留主要信息的前提下，把高维数据压缩到更少的维度，便于可视化或加速计算。

**聚类实例**：新闻网站有 100 万篇文章，没有人工分类。算法自动把它们聚成「科技、体育、财经、娱乐」等若干簇——注意算法并不给簇命名，簇的语义要由人去看样本后归纳。

**异常检测实例**：信用卡公司记录 1000 万笔「正常」交易，训练模型学习正常消费的模式。当某笔交易在深夜、异地、单笔金额高达平时消费的 50 倍时，模型判定它「明显异常」，触发风控拦截。

**直觉**：监督学习是「带着答案清单去考试」，无监督学习是「自己发现考卷里有几道题属于同一题型」。

**常见误区/注意点**：
- 误区一：以为无监督学习「没用」或「不如监督学习」。现实中大量数据没有标签，而无标签数据远比有标签数据容易获得。
- 误区二：以为聚类算法会输出「有含义的类别名」。算法只输出分组，命名/解释由人完成。
- 误区三：无监督学习的结果没有「对错」之分，只有「是否符合业务目标」之分，需要结合场景判断。

## 机器学习术语

**定义**：在正式学习前统一一套术语，避免后续章节概念混乱。

| 术语  | 英文                 | 一句话定义             | 房价预测示例                |
| --- | ------------------ | ----------------- | --------------------- |
| 训练集 | Training Set       | 用来训练模型的数据集合       | 1000 套房子的历史记录         |
| 样本  | Example / Instance | 训练集中的一条数据         | **1 套房子** = 一个样本      |
| 特征  | Feature (x)        | 样本的输入属性           | **面积 80 ㎡** = 特征（可多个） |
| 标签  | Label (y)          | 样本对应的正确输出         | **成交价 250 万** = 标签    |
| 模型  | Model              | 学到的 x → y 的映射函数 f | 「面积 → 房价」的预测函数        |
| 参数  | Parameter (w, b)   | 模型内部可调的数字，训练就是调它们 | 面积每增加 1 ㎡ 房价涨 w 万元    |

**一句话串联**：训练集里有 **1000 个样本**（1000 套房子），每个样本用**特征**（面积、卧室数）描述，带着**标签**（真实成交价）；学习算法从中找出一个**模型** f，模型的形状由**参数** w, b 决定；训练过程就是不断调整参数、让预测尽量接近标签。

**伪代码：一次训练的基本流程**

```
循环 直到误差不再下降：
    对 训练集中的每个样本:
        预测 = 模型(样本特征, 当前参数 w, b)
        误差 = 预测 与 标签 的差距
    更新参数 w, b，使总体误差变小
输出: 训练好的模型（含最优参数 w, b）
```

**常见误区/注意点**：
- 一个样本可能有很多特征（面积、卧室数、地段），特征是「向量」而非单个数字。
- 标签只在训练集里有；对真正要预测的新数据，标签是未知的（那正是我们要预测的东西）。
- 「模型」是训练产出的函数，不是数据本身，也不是算法本身。

## 符号约定

**定义**：为方便描述，全课程统一使用以下数学符号（后续每章都会沿用）。

| 符号   | 含义            | 房价预测示例                      |
| ---- | ------------- | --------------------------- |
| m    | 训练样本的个数       | m = 1000，即有 1000 套房子的数据     |
| x    | 特征（单个样本的输入）   | 某套房子的面积 80 ㎡                |
| x⁽ⁱ⁾ | 第 i 个样本的特征    | 第 5 套房子的面积 x⁽⁵⁾ = 95 ㎡      |
| y⁽ⁱ⁾ | 第 i 个样本的标签    | 第 5 套房子的成交价 y⁽⁵⁾ = 280 万    |
| f(x) | 模型对输入 x 的预测输出 | f(80) = 252 万，即模型对该房估 252 万 |
| w    | 权重参数（weights） | 面积每 +1 ㎡，预测价约 +w 万          |
| b    | 偏置参数（bias）    | 面积为零时的基准房价（截距）              |

**伪代码：用符号描述线性模型与训练目标**

```
输入: 训练集 {(x⁽¹⁾, y⁽¹⁾), (x⁽²⁾, y⁽²⁾), ..., (x⁽ᵐ⁾, y⁽ᵐ⁾)}
模型: f(x) = w·x + b          # 最简单的线性模型
目标: 找到 w, b，使对所有 i，f(x⁽ⁱ⁾) ≈ y⁽ⁱ⁾
```

其中上标 ⁽ⁱ⁾ 是**样本编号**（不是幂次），务必与数学中的指数区分开。

**实例**：设 m = 3，三套房子的数据为：x⁽¹⁾=80, y⁽¹⁾=250；x⁽²⁾=95, y⁽²⁾=280；x⁽³⁾=60, y⁽³⁾=200。若当前模型参数 w=3, b=20，则 f(80)=3×80+20=260，与真实标签 250 相差 10——训练目标就是调整 w、b 让这类差距整体变小。

**直觉**：m 是「一共多少题」，x⁽ⁱ⁾、y⁽ⁱ⁾ 是「第 i 题的题干和标准答案」，f 是「考生（模型）」的作答，w、b 是考生脑子里的「答题参数」。

**常见误区/注意点**：
- x⁽ⁱ⁾ 的括号上标表示「第几个样本」，不是「几次方」，x² 与 x⁽²⁾ 含义完全不同。
- 当特征有多个时，x⁽ⁱ⁾ 本身是一个向量（如 x⁽ⁱ⁾ = (面积, 卧室数, 地段)），后续会引入向量表示。
- w 可以是多个（每个特征一个权重），b 通常只有一个；本章先以单个 w 入门。

## 小结

- **主线一：如何定义模型 f**。机器学习第一步是选一个模型结构，最简单的入门形式是线性模型 f(x) = w·x + b；f 的好坏取决于参数 w, b。
- **主线二：如何找到最优参数 w, b**。训练过程就是不断调整 w, b，使模型在所有训练样本上的预测 f(x⁽ⁱ⁾) 尽量接近标签 y⁽ⁱ⁾——后续「代价函数 + 梯度下降」章节将系统解决这个问题。
- 两大范式回顾：有标签数据 → 监督学习（回归 / 分类）；无标签数据 → 无监督学习（聚类 / 异常检测 / 降维）。
- 术语回顾：训练集由 m 个样本 (x⁽ⁱ⁾, y⁽ⁱ⁾) 组成，特征 x 进、标签 y 出，中间是参数 w, b 决定的模型 f。

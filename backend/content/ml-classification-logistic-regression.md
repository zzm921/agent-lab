## 卡片：为什么线性回归不适合分类

**定义**：分类标签是离散类别（0/1），而线性回归输出连续实数，直接拿它做分类，输出既会越界，又会被异常样本带偏。场景：用肿瘤大小 x 判断肿瘤是恶性（y=1）还是良性（y=0）。

**问题一：输出越界，无法解释为概率**——直线 y = wx + b 的取值覆盖整个实数轴，可能输出负值（如 -0.2）或大于 1（如 1.4）。「负概率」「超过 100% 的概率」都没有意义。

**问题二：边界会被异常样本带偏（手算演示）**

现有 3 个样本：(x=1,y=0)、(x=2,y=0)、(x=3,y=1)。最小二乘拟合（均值 x̄=2，ȳ=1/3）：
```
w = Σ(x-x̄)(y-ȳ) / Σ(x-x̄)² = [(-1)(-1/3)+0·0+1·(2/3)] / [1+0+1] = 0.5
b = ȳ - w·x̄ = 1/3 - 0.5×2 = -2/3 ≈ -0.667
```
得直线 y = 0.5x - 0.667：x=1 时预测 -0.167（负值）；x=4 时预测 1.333（大于 1）。以 0.5 为阈值，边界在 x = 2.33。

加入一个异常样本 (x=10, y=1) 后重新拟合（x̄=4，ȳ=0.5）：
```
w = [(-3)(-0.5)+(-2)(-0.5)+(-1)(0.5)+6·0.5] / [9+4+1+36] = 5/50 = 0.1
b = 0.5 - 0.1×4 = 0.1
```
新直线 y = 0.1x + 0.1，边界右移到 x = 4，原本 (x=3, y=1) 的真实恶性样本被划到「良性」一侧——一条样本就拖跑了整个决策边界。

**解决**：改用逻辑回归——线性输出 z 经 Sigmoid 压到 (0,1)，天然是「类别 1 的概率」。名字带「回归」但实际是分类算法。

> 直觉：线性回归追求「值逼近某个数」，分类追求「落在哪一侧」，目标不同，工具不通用。

**常见误区/注意点**
1. 不要把线性回归的预测值当概率：可能小于 0 或大于 1。
2. 逻辑回归是分类算法而非回归，概念题常考。
3. 一个异常点就能全局移动线性回归的整条直线。

## 卡片：逻辑回归模型

**定义**：逻辑回归 = 线性函数 z = w·x + b 套一层 Sigmoid 函数，把输出压到 0~1，得到样本属于类别 1 的概率 f(x)。

**公式（伪代码）**
```
z = w·x + b = w₁x₁ + w₂x₂ + ... + wₙxₙ + b
f(x) = g(z) = 1 / (1 + e^(-z))
```

**符号表**

| 符号 | 含义 |
|---|---|
| x | 输入特征向量，x = [x₁, x₂, ..., xₙ] |
| w | 特征权重向量，w = [w₁, w₂, ..., wₙ] |
| b | 偏置（截距），常数项 |
| z | 线性组合结果，z = w·x + b |
| g(z) | Sigmoid（逻辑）函数 |
| f(x) | 输出：P(y=1 \| x)，即给定 x 时 y=1 的概率 |
| e | 自然常数，约 2.718 |

**为什么 Sigmoid 能把输出压到 0~1**：e^(-z) > 0 恒成立，分母 1 + e^(-z) 恒大于 1，故 0 < g(z) < 1 永远不越界。z 很大时 g(z) 趋近 1，z 很负时趋近 0，z=0 时 g(0) = 0.5，正好是「五五开」的分界。

**g(z) 取值表（可心算核对）**

| z | e^(-z) | g(z) = 1/(1+e^(-z)) |
|---|---|---|
| -5 | 约 148.41 | 约 0.007 |
| -1 | 约 2.718 | 约 0.269 |
| 0 | 1 | 0.500 |
| 1 | 约 0.368 | 约 0.731 |
| 5 | 约 0.0067 | 约 0.993 |

**实例（手算）**：训练好 w = [0.5, -0.2]、b = 0.1（x₁ 为肿瘤大小、x₂ 为边界光滑度，越大越像恶性）。新样本 x = [2, 3]：
```
z = w·x + b = 0.5×2 + (-0.2)×3 + 0.1 = 1.0 - 0.6 + 0.1 = 0.5
f(x) = g(0.5) = 1 / (1 + e^(-0.5)) = 1 / (1 + 0.6065) = 1/1.6065 ≈ 0.622
```
该样本为恶性肿瘤的概率约 62%，良性概率 = 1 - 0.622 = 0.378。

**预测规则**
```
若 f(x) ≥ 0.5：预测为类别 1（恶性）
若 f(x) < 0.5：预测为类别 0（良性）
```

**常见误区/注意点**
1. f(x) 是概率而非「确定性程度」：0.62 表示倾向恶性，仍有 38% 的不确定性。
2. 标签 0/1 是类别编号，不代表数值大小，不能做算术平均。
3. Sigmoid 对 |z| 不敏感：z=10 与 z=100 的概率都约等于 1，无法区分「多自信」。

## 卡片：决策边界（Decision Boundary）

**定义**：决策边界是把类别 0 和类别 1 分开的线（或面、曲线），由参数 w、b 决定，而不是由数据集直接画出来的。

**为什么边界是 z = 0**：分类以 f(x) = 0.5 为阈值，而 g(z) = 0.5 当且仅当 z = 0，故边界条件等价于 z = w·x + b = 0。

**线性边界实例**：设 w₁ = 1，w₂ = -1，b = -1，则 w₁x₁ + w₂x₂ + b = 0 化为 x₂ = x₁ - 1——一条斜率为 1、截距为 -1 的直线，一侧样本 f(x) > 0.5 判为类别 1，另一侧判为类别 0。

**非线性边界实例（多项式特征）**：只靠 x₁、x₂ 只能得到直线，构造多项式特征后能生成曲线。例如圆形边界 x₁² + x₂² = 1：令新特征 u₁ = x₁²、u₂ = x₂²，线性函数写成 w₁u₁ + w₂u₂ + b = 0；取 w₁ = w₂ = 1、b = -1，即 u₁ + u₂ - 1 = 0，等价于 x₁² + x₂² = 1——「单位圆内部」判为类别 0，「圆外部」判为类别 1。

**为什么多项式特征能产生复杂边界**：线性边界只能表达直线/平面；构造 x₁²、x₂²、x₁x₂ 等高阶组合后，z 是这些新特征的线性组合，z = 0 在原始特征空间里就是曲线、圆、椭圆等复杂形状。特征阶数越高边界越灵活，但也越容易过拟合。

> 直觉：决策边界像国境线——参数定了国境线就定了；多项式特征相当于允许国境线拐弯。

**常见误区/注意点**
1. 决策边界是参数函数，不是「训练集的边界」；换参数边界就变。
2. 多项式特征属于特征工程，是手动构造的新特征，不是模型自带能力。
3. 特征越丰富边界越灵活，需搭配正则化，否则曲线会「扭着穿过每个点」造成过拟合。

## 卡片：对数损失代价函数（重点）

**定义**：代价函数 J(w,b) 衡量「当前参数下预测与真实标签的整体差距」。逻辑回归用对数损失（Log Loss / 交叉熵），而不是平方误差。

**公式（伪代码）**
```
单个样本 (x, y) 的损失：
    L(f, y) = -y·log(f) - (1-y)·log(1-f)
整体代价：
    J(w,b) = (1/m) · Σᵢ [ -y⁽ⁱ⁾·log(f⁽ⁱ⁾) - (1-y⁽ⁱ⁾)·log(1-f⁽ⁱ⁾) ]
```

**符号表**

| 符号 | 含义 |
|---|---|
| m | 训练样本个数 |
| y⁽ⁱ⁾ | 第 i 个样本的真实标签，只能是 0 或 1 |
| f⁽ⁱ⁾ | 第 i 个样本的预测概率 f(x⁽ⁱ⁾)，在 (0,1) 之间 |
| log | 自然对数（以 e 为底） |
| L(f, y) | 单个样本的损失 |

**逐项解释：-y·log(f) 和 -(1-y)·log(1-f)**
- 当 y=1 时：第一项 -1·log(f) 生效，第二项为 0。希望 f 越大越好：f→1 时损失→0；f→0 时 log(0)→-∞，损失→+∞，猛烈惩罚。
- 当 y=0 时：第一项为 0，第二项 -1·log(1-f) 生效。希望 f 越小越好：f→0 时损失→0；f→1 时损失→+∞。

一句话：**每一项只在「真实类别」对应的那侧计分**，预测越接近真实标签损失越小。

**为什么不能用平方误差（非凸问题）**
- 平方误差对线性回归好用，因为 f 是 z 的线性函数，J 关于参数是凸的（像一个碗，只有一个谷底）；
- 逻辑回归中 f = g(z) 是 S 形曲线，平方后 J 不再凸：曲线呈波浪状、有多个波谷（局部最优），梯度下降可能停在浅波谷里，永远到不了全局最优点；
- 对数损失恰好保证 J 是凸的（参数空间只有一个全局最小点），梯度下降才能稳定收敛。

**实例（手算，两个样本）**

| 样本 | 真实标签 y | 预测概率 f |
|---|---|---|
| 1 | 1 | 0.8 |
| 2 | 0 | 0.4 |

```
样本1（y=1, f=0.8）：L₁ = -1·log(0.8) - 0 = -log(0.8) = -(-0.223) = 0.223
样本2（y=0, f=0.4）：L₂ = -0 - 1·log(1-0.4) = -log(0.6) = -(-0.511) = 0.511
整体代价：J = (L₁ + L₂) / 2 = (0.223 + 0.511) / 2 = 0.367
```
**-log(0.8) ≈ 0.223 的含义**：真实标签是 1，模型给出 80% 的概率，已经很接近，所以惩罚很小（远小于「预测 20%」时的 -log(0.2) ≈ 1.609）。损失越小代表预测越接近真实。

> 直觉：把概率看作「下注信心」，对数损失就是「错得越离谱罚得越狠」——真相是 1 时预测 1% 的惩罚远比预测 40% 重得多。

**常见误区/注意点**
1. 平方误差不是「不能用」，而是「对逻辑回归非凸、难以收敛」，所以才选对数损失。
2. y 取 0/1 时，两项有且只有一项生效，不要两项都算。
3. log 里的 f 和 1-f 必须在 (0,1) 内；为避免 log(0) 爆炸，工程上要做数值裁剪（clipping）。

## 卡片：梯度下降

**定义**：梯度下降通过反复「沿 J(w,b) 下降最快的方向迈一小步」迭代更新参数，使代价函数越来越小。

**更新公式（伪代码）**
```
重复直到收敛：
    wⱼ := wⱼ - α · (1/m) · Σᵢ ( f(x⁽ⁱ⁾) - y⁽ⁱ⁾ ) · xⱼ⁽ⁱ⁾     （对所有 j）
    b  := b  - α · (1/m) · Σᵢ ( f(x⁽ⁱ⁾) - y⁽ⁱ⁾ )
```

**与线性回归的异同**
- 相同点：更新公式形式完全一样，都是「当前参数 - 学习率 × 平均梯度」；
- 不同点：线性回归中 f 是纯线性输出 w·x+b，逻辑回归中 f 是 Sigmoid 输出 g(z)。公式「长得一样」是对数损失求导后的简洁形式。

**实例（手算一次迭代）**：单特征 3 个样本 (x=1,y=1)、(x=2,y=0)、(x=3,y=1)，初始 w=0、b=0，学习率 α=0.5。每个样本预测 f = g(0) = 0.5：
```
误差 e⁽ⁱ⁾ = f⁽ⁱ⁾ - y⁽ⁱ⁾：
样本1：e = 0.5 - 1 = -0.5
样本2：e = 0.5 - 0 =  0.5
样本3：e = 0.5 - 1 = -0.5
```
平均梯度：
```
∂J/∂w = (1/3)·[(-0.5)(1)+(0.5)(2)+(-0.5)(3)] = (1/3)·(-1.0) = -0.333
∂J/∂b = (1/3)·[-0.5+0.5+(-0.5)] = (1/3)·(-0.5) = -0.167
```
更新参数：
```
w := 0 - 0.5 × (-0.333) = 0.167
b := 0 - 0.5 × (-0.167) = 0.083
```
一次迭代后 w=0.167、b=0.083，反复迭代会逼近让 J 最小的参数。配合特征缩放（把各特征归一到相近量级）可显著加速收敛。

> 直觉：像蒙眼下山——每次探哪个方向最陡（梯度），朝那个方向挪一小步（学习率），反复试探总能到谷底。

**常见误区/注意点**
1. 学习率 α 太大「跨过谷底来回震荡」不收敛，太小收敛太慢。
2. 特征量级差异巨大时（x₁ 在 0~1、x₂ 在 0~10000），必须做特征缩放。
3. 梯度公式形式虽与线性回归相同，但 f 是 Sigmoid 输出。

## 过拟合与欠拟合

**定义**
- **欠拟合（Underfitting，高偏差）**：模型太简单，连训练数据规律都没学出来，训练误差和测试误差都很高。
- **过拟合（Overfitting，高方差）**：模型太复杂，把训练数据连同噪声一起背下来了，训练误差极低、测试误差很高，泛化差。

**如何识别（看训练/测试误差）**

| 情况 | 训练误差 | 测试（验证）误差 | 判断 |
|---|---|---|---|
| 两条都高且接近 | 高 | 高 | 欠拟合 |
| 训练低、测试高 | 低 | 高 | 过拟合 |
| 两条都低且接近 | 低 | 低 | 拟合良好 |

**实例（房价预测）**
- 一次多项式（直线）拟合：捕捉不到非线性趋势 → 欠拟合；
- 几十次多项式拟合：曲线扭曲穿过每个训练点，换数据就预测离谱 → 过拟合。

**缓解过拟合的方法（列表）**
1. **收集更多训练数据**：最简单直接，噪声被「平均」掉，模型不敢乱扭。
2. **减少特征数量**：去掉无关/冗余特征（但要小心误删有用信息）。
3. **正则化（Regularization）**：保留全部特征，但惩罚过大的权重，让模型更平滑。
4. （工程上还可）**数据增强、早停、交叉验证选模型复杂度**等。

> 直觉：欠拟合是「没学够」，过拟合是「背答案背太狠」，正则化是「答题不许写得太花哨」。

**常见误区/注意点**
1. 欠拟合与过拟合分别在「学不会」端和「学过头」端，缓解手段相反。
2. 判断过拟合必须同时看训练误差和测试误差，只看一个会误判。
3. 特征越多不一定越好，样本量不大时更容易过拟合。

## 正则化（Regularization）

**定义**：正则化在代价函数里加一项「权重大小的惩罚」，鼓励模型用尽量小的权重，让曲线更平滑、抑制过拟合。

**为什么加入 (λ/2m)·Σwⱼ²**：过拟合常伴随某些权重绝对值很大，曲线被大权重扯得剧烈弯曲；加入权重平方和后，模型为降低总代价会主动压低权重，输出对单个特征的依赖变小，曲线变平滑；除以 2m 是为了求导时系数整齐（见下方推导），λ 调节惩罚力度。

**正则化后的代价函数（伪代码）**
```
线性回归：J(w,b) = (1/2m)·Σᵢ (f⁽ⁱ⁾-y⁽ⁱ⁾)² + (λ/2m)·Σⱼ wⱼ²
逻辑回归：J(w,b) = (1/m)·Σᵢ [-y⁽ⁱ⁾log(f⁽ⁱ⁾)-(1-y⁽ⁱ⁾)log(1-f⁽ⁱ⁾)] + (λ/2m)·Σⱼ wⱼ²
```

**符号表**

| 符号 | 含义 |
|---|---|
| λ | 正则化参数，控制惩罚强度（手动调的「旋钮」） |
| m | 样本个数 |
| Σⱼ wⱼ² | 所有权重（j=1 到 n）的平方和，即 L2 惩罚 |
| 备注 | 通常不惩罚 b（偏置只平移曲线，不影响弯曲程度） |

**λ 取不同值的对比**

| λ | 惩罚力度 | 效果 |
|---|---|---|
| λ=0 | 无惩罚 | 原模型，容易过拟合 |
| λ 很小 | 轻微 | 几乎没变化，仍可能过拟合 |
| λ 合适 | 适中 | 权重适度缩小，曲线平滑且拟合良好 |
| λ 很大 | 极强 | 权重被压到接近 0，模型退化成「近似常数」→ 欠拟合 |

**实例（手算惩罚项）**：设 λ=0.01、m=4、当前权重平方和 Σwⱼ² = 100：
```
惩罚项 = (λ/2m)·Σwⱼ² = (0.01/8) × 100 = 0.00125 × 100 = 0.125
```
含义：假设原损失 J 为 1.000，加入正则化后 J 变成 1.125。模型必须权衡「拟合误差」与「权重平方和」，为省下这 0.125 的开销，梯度下降会主动把大权重往 0 压。λ 越大，「砍权重」的动力越强。

**梯度下降更新中的 (λ/m)·wⱼ 项从哪来**：对惩罚项求偏导得 (λ/m)·wⱼ，把这一项并入梯度后更新公式变为：
```
∂/∂wⱼ [ (λ/2m)·Σⱼ wⱼ² ] = (λ/2m) · 2wⱼ = (λ/m) · wⱼ

wⱼ := wⱼ - α · [ (1/m)·Σᵢ (f⁽ⁱ⁾-y⁽ⁱ⁾)·xⱼ⁽ⁱ⁾ + (λ/m)·wⱼ ]
b  := b  - α · (1/m)·Σᵢ (f⁽ⁱ⁾-y⁽ⁱ⁾)          （b 不参与惩罚）
```
每次更新除沿普通梯度下降外，还多减了 (λ/m)·wⱼ——等价于每一步把 wⱼ 额外往 0 方向拉一点，防止单个特征的权重失控地变大。

> 直觉：正则化像「配重约束」——允许你有大权重，但每用一份大权重都要交税（λ 决定税率），于是模型宁愿把权重摊得更均匀、更平滑。

**常见误区/注意点**
1. 惩罚对象是 w（特征权重），一般不动 b。
2. λ 不是越大越好：太大会把所有权重压没，模型退化成常数 → 欠拟合。
3. λ 是超参数，应通过验证集/交叉验证挑选，而不是只看训练集表现。

## 易错点与要点

| 要点                 | 说明                               |
| ------------------ | -------------------------------- |
| 逻辑回归是分类算法          | 名字带「回归」，但输出是 0~1 概率，用途是分类        |
| 平方误差不能用于逻辑回归       | 代入 Sigmoid 后代价函数非凸（多个波谷），必须用对数损失 |
| Sigmoid 输出 ∈ (0,1) | 因为 e^(-z) > 0，分母恒大于 1，永远不会越界     |
| f(x)=0.5 对应 z=0    | 决策边界就是 w·x+b=0，由参数决定             |
| 多项式特征能生成非线性边界      | 如 x₁²+x₂²=1 的圆形边界，但小心过拟合         |
| 梯度公式「形似」线性回归       | 但 f 是 Sigmoid 输出，含义完全不同          |
| 过拟合看「训练低、测试高」      | 只盯训练误差会误判；欠拟合则是两边都高              |
| λ 需要调              | 太大欠拟合、太小过拟合，用验证集选择合适 λ           |
| 正则化不惩罚 b           | 惩罚项只对 w 的平方和求和                   |
| 梯度更新中 (λ/m)·wⱼ     | 来自 (λ/2m)Σwⱼ² 求导，作用是把权重往 0 方向额外拉 |

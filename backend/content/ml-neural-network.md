## 为什么需要神经网络
**定义**：神经网络是通过多层"神经元"自动学习特征、拟合非线性关系的机器学习模型，它把"人工设计特征 + 线性模型"替换为"自动学特征 + 非线性模型"。

**公式（线性模型的局限）**：
```
y = w·x + b        （线性模型：输出是输入的线性组合；多层线性复合后仍是线性）
```

**符号表**：
- x：输入特征向量；w：权重向量；b：偏置（截距）；y：模型输出

**为什么（设计动机）**：
1. 线性模型表达力有限：图像、语音等任务的决策边界常是非线性的，一条直线/一个平面分不开。
2. 手工特征工程费时费力：人工构造多项式特征（x₁²、x₁x₂…）维度爆炸，且"该用哪些特征"全靠经验试错。
3. 神经网络自动学特征：低层学简单模式、高层组合出复杂模式。图像识别即典型例子——第一层学边缘和色块，第二层组合出眼睛、耳朵，最后一层判断整体像不像猫，特征完全由网络自动学习。

**直觉**：像一条"特征加工流水线"——原材料（像素）进去，每一层车间把半成品加工得更抽象，出口直接出结论。

**实例（反例：线性模型为何学不会 XOR）**：用 y = x₁ + x₂ − 1.5 学"异或"（相同为 0、相异为 1）：

| 输入 (x₁, x₂) | y = x₁ + x₂ − 1.5 | 阈值后（>0 判 1） | 目标 |
|---|---|---|---|
| (0, 0) | −1.5 | 0 | 0 |
| (0, 1) | −0.5 | 0 | 1 |
| (1, 0) | −0.5 | 0 | 1 |
| (1, 1) | 0.5 | 1 | 0 |

4 个样本错 2 个，且无论怎么调权重都无法全对——"相异为 1"的点无法用一条直线分开；加一层带非线性激活的隐藏层即可解决，这正是需要神经网络的最直接答案。

**术语**：
- 层（layer）：神经网络的不同阶段，输入层、隐藏层、输出层。
- 神经元（neuron）：每个层的基本计算单元，负责对输入加权求和、过非线性激活函数。
- 隐藏层（hidden layer）：神经网络中间层，对输入进行特征提取、组合。
- 激活函数（activation function）：神经元对线性加权结果的非线性变换，常用 Sigmoid、ReLU 等。
- 激活值（activation value）：神经元对输入加权求和后的结果，再过激活函数得到输出。
- 输出（output）：神经网络最后一层的激活值，即模型的预测结果。



**常见误区/注意点**：
- 别以为层数越多越好：前提是每层有非线性、数据量足够。
- 数据量小、问题本身线性时先试线性模型：更稳、更可解释。



## 神经元与激活函数
**定义**：神经元是基本计算单元——先对输入加权求和再加偏置，再过非线性激活函数得到输出。

**公式**：
```
a = g( w·x + b )       w·x = Σᵢ wᵢ·xᵢ = w₁x₁ + w₂x₂ + … + wₙxₙ
```

**符号表**：
- x：输入向量；w：权重向量（wᵢ 表示第 i 个输入的重要程度，可正可负）；b：偏置，控制激活难易
- z = w·x + b：线性加权结果；g：激活函数（必须非线性）；a：神经元的输出

**为什么（设计动机）**：
1. 为什么需要非线性：若 g 是线性函数，多层神经元的复合仍是线性函数，拟合不了弯曲的决策边界。
2. 为什么用 Sigmoid：输出被压缩到 (0,1)，可解释为概率，适合二分类输出层。
3. 为什么 ReLU 更好：Sigmoid 在 |z| 大时饱和、梯度几乎为 0，深层网络中梯度会"消失"导致训练不动；ReLU 正区间梯度恒为 1，收敛快、计算省。

**直觉**：像"安检门"——先给各输入打分（加权和），总分超过"火线"（激活函数）才放行。

**激活函数速查表**：

| 激活函数 | 公式 | 输出范围 | 适用场景 |
|---|---|---|---|
| Sigmoid | g(z) = 1 / (1 + e⁻ᶻ) | (0, 1) | 二分类输出层（输出概率） |
| ReLU | g(z) = max(0, z) | [0, +∞) | 隐藏层首选，收敛快、无饱和 |
| 线性 | g(z) = z | (−∞, +∞) | 回归输出层（预测数值） |

**选择原则**：隐藏层默认用 ReLU；输出层按任务选——二分类 Sigmoid、多分类 Softmax（见后文卡片）、回归线性。

**实例（手算）**：输入 x = [1, 2]，权重 w = [0.5, −0.3]，偏置 b = 0.1。

```
z = 0.5×1 + (−0.3)×2 + 0.1 = 0.5 − 0.6 + 0.1 = 0.0
Sigmoid(0.0) = 1 / (1 + e⁰) = 0.5       ReLU(0.0) = max(0, 0) = 0
```

延伸：若偏置改为 b = 0，则 z = 0.5 − 0.6 = −0.1，此时 Sigmoid(−0.1) ≈ 0.475，ReLU(−0.1) = 0——ReLU 对非正输入一律"截断"为 0，这正是它计算快、能产生稀疏激活的原因。

**常见误区/注意点**：
- Sigmoid 别用于隐藏层：易饱和、梯度消失、输出非零中心。
- 输出层别用 ReLU：回归要预测负数时会被直接截断。
- 权重初始化不能全 0：所有神经元对称退化，网络学不动。

## 网络结构与前向传播
**定义**：前向传播（Forward Propagation）指信息从输入层出发，逐层"加权求和 + 激活"，最终到达输出层得到预测值的过程。

**网络结构（文字图，2→3→1）**：
```
输入层（2 个输入）      隐藏层（3 个神经元, ReLU）      输出层（1 个输出）
     x₁ = 1.0 ────┐
                   ├── h₁（a₁）──────┐
     x₂ = 2.0 ────┼── h₂（a₂）──────┼── o（预测 y）
                   ├── h₃（a₃）──────┘
                   └──（全连接：每个输入都连到每个隐藏神经元）
```
输入层承载原始特征不做计算；隐藏层可有 1 个或多个，神经元越多表达力越强（也越易过拟合）；输出层给出最终预测。

**公式/伪代码**：
```
对每一层 L（从第 1 个隐藏层到输出层）：
    对 L 中的每个神经元 j：
        zⱼ = Σᵢ (aᵢ · wᵢⱼ) + bⱼ        # aᵢ 是上一层第 i 个神经元的输出
        aⱼ = g(zⱼ)                      # g 为该层激活函数
输出：最后一层的 a（预测值）
```

**符号表**：
- aᵢ：上一层第 i 个神经元的输出（输入层时即原始特征 xᵢ）；wᵢⱼ：上一层第 i 个神经元连到本层第 j 个神经元的权重；bⱼ：本层偏置
- zⱼ：加权和；g：激活函数；aⱼ：本层神经元的输出

**为什么（设计动机）**：
- 逐层抽象：每一层把上一层特征重新组合，低层 → 高层 → 结论，本质是"自动特征工程"的机械过程。
- 统一计算：无论网络多深，前向传播都只重复"加权和 + 激活"两个动作，适合矩阵运算并行加速。

**直觉**：信息逐层向前流动，像工厂流水线——原料进、每道工序加工一次、成品出。

**实例（完整手算）**：网络 2→3→1，输入 x = [1.0, 2.0]，隐藏层用 ReLU、输出层用线性激活（回归任务）。

权重与偏置：
```
h₁：w₁₁ = 0.5,  w₁₂ = −0.3, b₁ = 0.1
h₂：w₂₁ = 0.8,  w₂₂ = 0.4,  b₂ = −0.2
h₃：w₃₁ = −0.6, w₃₂ = 1.1,  b₃ = 0.0
o： w₀₁ = 0.7,  w₀₂ = −0.5, w₀₃ = 0.9, b₀ = 0.2
```

第 1 步，算隐藏层每个神经元的加权和与激活值：
```
z₁ = 0.5×1.0 + (−0.3)×2.0 + 0.1 = 0.0   → a₁ = ReLU(0.0) = 0
z₂ = 0.8×1.0 + 0.4×2.0 + (−0.2) = 1.4   → a₂ = ReLU(1.4) = 1.4
z₃ = (−0.6)×1.0 + 1.1×2.0 + 0.0 = 1.6   → a₃ = ReLU(1.6) = 1.6
```

第 2 步，算输出层：
```
y = 0.7×a₁ + (−0.5)×a₂ + 0.9×a₃ + 0.2
  = 0.7×0 + (−0.5)×1.4 + 0.9×1.6 + 0.2
  = 0 − 0.7 + 1.44 + 0.2
  = 0.94
```
预测 y = 0.94。注意 a₁ 被 ReLU 压成 0，对输出没有贡献——这正是稀疏激活的体现。

**常见误区/注意点**：
- 输入层不算"层"：不做计算，很多框架统计层数时不把它计入。
- 前向传播不是只算一次：每更新一次参数都要重新前向传播。
- 手算与代码有精度差异：手算用 ≈ 记录近似值，代码用浮点数，别逐位对比。

## 多分类与 Softmax
**定义**：Softmax 把 K 个实数（logits）转化为 K 个和为 1 的概率，用于"从 K 个类别中选一个"的多分类任务（如识别 0–9 的手写数字）。

**公式**：
```
对类别 j（j = 1, 2, …, K）：
    aⱼ = eᶻⱼ / Σₖ eᶻₖ
z = [z₁, …, z_K] 是输出层 K 个神经元的原始值（logits）
预测类别 = argmaxⱼ aⱼ（概率最大的类别）
```

**符号表**：
- K：类别总数；zⱼ：第 j 类的 logit（任意实数，可正可负）
- eᶻⱼ：对 zⱼ 取指数，保证结果为正并拉大各类别差异；Σₖ eᶻₖ：所有指数值之和（归一化分母）
- aⱼ：第 j 类概率，0 < aⱼ < 1，且 Σⱼ aⱼ = 1

**为什么（设计动机）**：
1. 为什么用指数 eᶻ：logit 可为负数而概率必须为正，eᶻ 天然把负数映射成正数；且指数放大差距，让最有把握的类别概率更高。
2. 为什么除以指数和：把所有指数值归一化，使 K 个输出恰好构成一个概率分布（和为 1）。
3. 与 Sigmoid 的关系：K = 2 时 Softmax 在数学上退化为 Sigmoid，可看作 Sigmoid 的多类推广。

**直觉**：像"比赛打分换算成获奖概率"——先给每个选手的分数取指数，再按比例瓜分 100% 的概率。

**实例（手算，3 分类）**：输出层 logits：z = [2.0, 1.0, 0.5]。

第 1 步，求指数值；第 2 步，求分母：
```
e^2.0 ≈ 7.3891
e^1.0 ≈ 2.7183
e^0.5 ≈ 1.6487
Z = 7.3891 + 2.7183 + 1.6487 = 11.7561
```

第 3 步，求每个类别的概率：
```
a₁ = 7.3891 / 11.7561 ≈ 0.6285
a₂ = 2.7183 / 11.7561 ≈ 0.2312
a₃ = 1.6487 / 11.7561 ≈ 0.1403
验证：0.6285 + 0.2312 + 0.1403 = 1.0000 ≈ 1 ✓
```

预测类别 1（概率约 0.63 最大）。注意 z₂ 与 z₃ 只差 0.5，但指数放大后 a₂ ≈ 1.65×a₃——指数确实放大了差异。

**二分类 / 多分类 / 多标签的区别**：

| 任务 | 输出层结构 | 输出 | 语义 |
|---|---|---|---|
| 二分类 | 1 个神经元 + Sigmoid | 1 个概率 | 是/否，如"是不是猫" |
| 多分类 | K 个神经元 + Softmax | K 个概率，和为 1 | 选一个，如"猫/狗/鸟" |
| 多标签 | K 个神经元各自接 Sigmoid | K 个独立概率 | 可同时多个为 1，如"图里有猫也有狗" |

**常见误区/注意点**：
- 多标签别用 Softmax：强制和为 1 会让各类概率互相挤压，应每个类别独立用 Sigmoid。
- 数值稳定性：z 很大时 eᶻ 会溢出，实现上通常先对所有 z 减去最大值（结果不变）。
- 训练常用"Softmax + 交叉熵"组合，其梯度形式很简洁（a − one-hot 标签）。

## 训练神经网络
**定义**：训练就是通过"前向传播 → 计算代价 → 反向传播求梯度 → 梯度下降更新参数"的循环，不断缩小预测与真实标签之间的差距。

**伪代码（三步走）**：
```
重复（直到代价收敛）：
    1. 前向传播：   逐层计算输出，得到预测 ŷ
    2. 计算代价：   J = 交叉熵（分类）/ 平方误差（回归）
    3. 反向传播 + 更新：
        从输出层往回，用链式法则逐层求 ∂J/∂w、∂J/∂b
        每个参数：参数 ← 参数 − 学习率 × 梯度
```

**符号表**：
- ŷ：模型预测；y：真实标签；J：代价函数；η：学习率（更新步长）
- ∂J/∂w、∂J/∂b：代价对权重、偏置的梯度，指示参数往哪个方向调能减小 J

**为什么（设计动机）**：
1. 为什么需要反向传播：深层网络参数成千上万，逐一求导不现实；链式法则把输出层误差"逐层传回"，每层只需本地求导，计算量可控。
2. 为什么"从后往前"：输出层误差对最后一层影响最直接，误差沿计算图往前传，每层都知道自己该为误差负多少责。
3. 为什么用 Adam：普通梯度下降对所有参数共用一个学习率，容易踩不准；Adam 为每个参数自适应调节学习率，收敛更快更稳。

**直觉**：像"下山"——代价函数是地形，梯度是坡度方向，梯度下降沿最陡方向迈小步；反向传播负责算出每个参数在坡上的朝向。

**优化技巧**：
- Adam 优化器：自动为每个参数调节学习率，一般作为默认首选。
- 小批量训练（Mini-batch）：每次随机取一小批（如 32/64 个）样本更新，比全量快、比逐个稳。
- 学习率调试：观察代价曲线——收敛太慢调大，震荡不降调小。

**实例（代价曲线分析）**：

| 代价曲线形态 | 可能原因 | 处理 |
|---|---|---|
| 一直很平、几乎不降 | 学习率太小 / 特征未归一化 / 网络太浅 | 调大学习率、归一化特征、加深网络 |
| 剧烈震荡、不收敛 | 学习率太大 | 调小学习率 |
| 训练代价降、验证代价升 | 过拟合 | 增加数据、加正则化、早停 |
| 代价突然变成 NaN | 学习率过大导致数值爆炸 | 大幅调小学习率、梯度裁剪 |
| 先快后平、停在平台 | 陷入局部极小 / 鞍点 | 换 Adam、学习率衰减计划、增大模型 |

**常见误区/注意点**：
- 忘了归一化特征：梯度方向被大尺度特征主导，收敛很慢。
- 学习率一次调太大：代价不降反升，甚至直接 NaN。
- 只盯训练代价：训练代价低不代表泛化好，必须同时看验证集。

## 易错点与要点
**定义**：把神经网络实践中最常见的坑集中成一张清单，写代码或搭模型前先对照一遍，能省下大量调试时间。

**为什么（设计动机）**：坑大多不是"公式不会"，而是"配置不对"——激活函数、初始化、学习率、数据预处理、监控指标，任一出错都会导致不收敛或过拟合，且报错往往不明显，只能按清单逐项排查。

**伪代码（调试检查清单）**：
```
训练不收敛时按顺序排查：
    1. 看代价曲线：不降 → 学习率太小/结构问题；震荡 → 学习率太大
    2. 检查数据：标签是否正确、特征是否归一化、是否混入 NaN
    3. 检查输出层激活函数：分类用 Softmax/Sigmoid，回归用线性
    4. 检查初始化：不能全 0，用小随机数
    5. 检查过拟合：训练好但验证差 → 加数据/正则化/早停
```

**直觉**：像"考前划重点"——记住这些，模型基本不会出大问题。

**易错点清单**：

| 易错点 | 说明 |
|---|---|
| 隐藏层激活函数选错 | 隐藏层用 ReLU；别用 Sigmoid（饱和、梯度消失） |
| 没有非线性 | 没有激活函数，多层等价于一层线性模型，白搭 |
| 输出层与任务不匹配 | 二分类 Sigmoid、多分类 Softmax、多标签多个 Sigmoid、回归线性 |
| 权重初始化全 0 | 神经元对称退化，学不动；应使用小随机数 |
| 忘记归一化输入 | 特征尺度差异大，收敛极慢 |
| 学习率一刀切 | 太大震荡甚至 NaN，太小不收敛；先用默认值再按曲线调 |
| 只看训练代价 | 训练好 ≠ 泛化好，必须监控验证集防过拟合 |
| 反向传播理解偏差 | 记住"误差从后往前传 + 链式法则 + 梯度下降"，求导交给框架 |
| 过拟合 | 网络越大越易过拟合，配合正则化、更多数据、早停控制 |
| 调试入口 | 训练不收敛先看代价曲线：一直不降 → 学习率/网络结构问题 |

## 概述

梯度下降（Gradient Descent）是一种**迭代优化算法**：从某个初始参数 (w, b) 出发，沿代价函数 J 下降最快的方向（负梯度方向）反复迈小步，直到逼近使 J 最小的参数。

```
1. 任选初始参数 (w, b)
2. 重复直到 J 几乎不再变化：
   对每个参数 θⱼ 计算偏导数 ∂J/∂θⱼ
   沿负梯度方向更新：θⱼ := θⱼ − α · ∂J/∂θⱼ
3. 输出收敛后的 (w, b)
```

**直觉（下山比喻）**：蒙眼站在山顶要下山——每走一步前用脚探测四周哪边最陡，朝最陡的下坡方向迈一小步，站定后再重复，反复几百步后自然走到山谷最低点。梯度就是「脚下的坡度」，α 就是「步长」。

## 为什么是「负梯度」方向

对许多模型，直接令导数为 0 解方程往往不可行。梯度 ∇J 指向上升最快的方向，负梯度 −∇J 就是下降最快的方向：

- 谷底右侧曲线上升、斜率 > 0：w := w − α·(正数) → w 变小、向左靠拢；
- 谷底左侧曲线下降、斜率 < 0：w := w − α·(负数) → w 变大、向右靠拢。

导数的**符号**自动把参数推向谷底，导数的**大小**决定步幅——减号不能丢，丢了就朝上坡走。

## 凸函数与局部最优

- **局部最优**：若初始点落在一个小凹坑里，下山者会停在坑底——那是局部最低，不一定是全局最优；
- **线性回归为何放心用梯度下降**：平方误差代价函数是**凸函数**（碗状，只有一个谷底），从任意初始点出发都会收敛到同一个全局最优点。

## 同时更新（核心伪代码）

```
重复直到收敛：
    # 第一步：用「旧」的 w、b 计算两个偏导
    tmp_w := w − α · ∂J/∂w
    tmp_b := b − α · ∂J/∂b
    # 第二步：全部算完后再统一赋值
    w := tmp_w
    b := tmp_b
```

为什么必须同时更新：∂J/∂w 与 ∂J/∂b 都依赖**当前**的 w、b。若先更新 w、再用新 w 算 ∂J/∂b，第二步就沿了错误方向，容易走弯路、震荡甚至发散。**严禁逐个更新参数**。

## 学习率 α

α 控制每步位移量，本步实际移动距离 = α × |偏导|。

| α 取值 | 表现 |
|---|---|
| 过小 | 每步只挪一点点，最终能收敛但耗时极长 |
| 合适 | J 每轮稳定下降，收敛快且稳定 |
| 过大 | 一步跨过谷底冲到对侧来回震荡，J 不降反升甚至发散 |

**用 J 曲线判断收敛**：每轮记录 J(w, b) 画曲线——单调下降并趋于水平 → α 合适已收敛；震荡或上升 → α 过大应调小；下降极慢 → α 过小可调大。相邻两轮 J 变化小于阈值（如 10⁻³）即停止。

⚠️ 判断收敛要看 **J 是否趋于平稳**，而不是看 w、b 的数值或梯度绝对值。α 需手工试参，常见从 0.01、0.03、0.1、0.3 按约 3 倍间隔尝试。

## 用于线性回归（批量梯度下降）

把梯度下降套到平方误差代价函数上，得偏导：

```
∂J/∂w = (1/m) Σᵢ ( f(x⁽ⁱ⁾) − y⁽ⁱ⁾ ) · x⁽ⁱ⁾     ← 误差 × 该样本特征值
∂J/∂b = (1/m) Σᵢ ( f(x⁽ⁱ⁾) − y⁽ⁱ⁾ )
w := w − α · ∂J/∂w
b := b − α · ∂J/∂b
```

每个样本的贡献是「误差 × 该样本的特征值」：误差越大的样本被修正得越狠，特征值越大的样本其权重被修正得越猛。每一步都用**全部训练样本**计算梯度，故称「批量梯度下降」。多特征时每个 wⱼ 独立按同一模式更新。

## 特征缩放（收敛的前提）

若面积取值 0~2000、卧室数取值 0~5，量级相差 400 倍，代价函数等高线被拉成狭长椭圆，梯度方向与短轴近乎垂直，每一步都在「横穿」椭圆、左右折返，收敛极慢。

**标准化公式**：

```
x_scaled = (x − μ) / σ
```

μ 为该特征在所有样本上的均值，σ 为标准差（也可用最大−最小代替）。缩放后各特征量级接近 [−1, 1]，等高线接近正圆，梯度直指圆心、几步收敛。

⚠️ 缩放要用**训练集**算出的 μ、σ；预测新样本时沿用同一组，不要重新计算。多项式特征（x²、x³）比 x 大几个数量级时，缩放是**前提条件**，否则几乎无法收敛。

## 收益与边界

- 一套「下山」框架通吃所有可导模型，是神经网络的训练引擎；
- 掌握「同时更新 / J 判收敛 / 特征缩放」三大铁律，避免震荡与发散；
- 边界：梯度只保证「当前这一步」下降，非凸问题（如神经网络）不保证全局最优、对初始点敏感；批量梯度下降每轮扫全部样本，样本量大时开销高，可改用随机/小批量变体。

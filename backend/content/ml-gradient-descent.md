## 核心思想

**定义**：梯度下降（Gradient Descent）是一种迭代优化算法：从某个初始参数 (w, b) 出发，沿代价函数 J 下降最快的方向（负梯度方向）反复迈小步，直到逼近使 J 最小的参数。

**公式（伪代码）**：
```
1. 任选初始参数 (w, b)
2. 重复直到 J 几乎不再变化：
   对每个参数 θⱼ 计算偏导数 ∂J/∂θⱼ
   沿负梯度方向更新：θⱼ := θⱼ − α · ∂J/∂θⱼ
3. 输出收敛后的 (w, b)
```

**符号表**：

| 符号 | 含义 |
|---|---|
| J(w, b) | 代价函数，衡量参数 (w, b) 下模型的整体误差 |
| w, b | 模型参数（权重与偏置） |
| α | 学习率，控制每一步迈多大 |
| ∂J/∂w | J 对 w 的偏导数，即 w 方向的坡度 |

**为什么（设计动机）**：对许多模型，直接令导数为 0 解方程往往不可行（参数多、方程非线性）。梯度下降采用「走一步看一步」的贪心策略：梯度 ∇J 指向上升最快的方向，负梯度 −∇J 就是下降最快的方向，于是每次更新 θ := θ − α·∂J/∂θ，保证「当前这一步」代价下降；越靠近谷底坡度越缓、步子自动变小，最终停在谷底附近。

**直觉（下山比喻）**：想象蒙眼站在山顶要下山：每走一步前用脚探测四周哪边最陡，朝最陡的下坡方向迈一小步，站定后再重复，反复几百步后自然走到山谷最低点。梯度就是「脚下的坡度」，α 就是「步长」。

**实例**：设 J(w) = w²，最小值在 w = 0 处。在 w = 3 处 ∂J/∂w = 6（正坡度），更新使 w 变小、向左走向谷底；在 w = −3 处 ∂J/∂w = −6（负坡度），更新使 w 变大、向右走向谷底——从哪一侧出发都会自动收敛到 0。

**局部最优与全局最优**：山的形状不一定只有一个坑。若初始点落在一个小凹坑里，下山者会停在坑底——这是**局部最优**（某小范围内的最低点），但不一定是整座山最低的**全局最优**。不同初始点可能收敛到不同结果，因此初始值的选取对一般问题很重要。

**为什么线性回归的代价函数是凸函数**：平方误差代价函数的形状像一个碗，只有一个谷底、没有小凹坑，即**凸函数（convex function）**：
```
J 的剖面（碗状，凸函数，唯一的谷底 = 全局最优）：
   J
   │            ·
   │          ·   ·
   │        ·       ·
   │      ·           ·
   │    ·               ·
   └───┴─────────────────→ w
                 w*
```
对凸函数，从**任意**初始点出发，梯度下降都收敛到同一个全局最优点，这正是线性回归可以放心用梯度下降求解的根本原因。

**常见误区/注意点**：
- 梯度下降是迭代逼近，不是一次求解；需设定收敛阈值与最大迭代次数；
- 梯度只保证「当前这一步」下降，对非凸问题不保证到达全局最优；
- 凸函数无局部最优问题，但神经网络等非凸问题对初始点敏感。

## 梯度下降算法

**定义**：对参数 w 和 b，重复「用当前的（旧）参数算出偏导，再统一减去 α·偏导」的更新，直到代价函数收敛。

**伪代码（同时更新）**：
```
重复直到收敛：
    # 第一步：用“旧”的 w、b 计算两个偏导
    tmp_w := w − α · ∂J/∂w
    tmp_b := b − α · ∂J/∂b
    # 第二步：全部算完后再统一赋值
    w := tmp_w
    b := tmp_b
```

**符号表**：

| 符号 | 含义 |
|---|---|
| w, b | 待更新的两个参数 |
| α | 学习率（正数），控制步长 |
| ∂J/∂w, ∂J/∂b | J 对 w、b 的偏导数，即各方向的坡度 |
| tmp_w, tmp_b | 临时变量，保证「同时更新」 |

**为什么导数项能自动走向谷底**：谷底 w* 右侧曲线上升、斜率 > 0，则 w := w − α·(正数) 使 w 变小、向左靠拢；左侧曲线下降、斜率 < 0，则 w := w − α·(负数) = w + α·|负数| 使 w 变大、向右靠拢。导数的**符号**自动把参数推向谷底，导数的**大小**决定步幅——这正是「负梯度方向」的本质。

**直觉**：导数项是「坡度计」——往哪边走是下坡由导数的正负决定，坡度越陡这一步走得越远。

**实例（数字演算）**：假设当前 w = 3 处导数为 +5，α = 0.1：
```
w := 3 − 0.1 × 5 = 3 − 0.5 = 2.5   （导数为正，向左走）
```
再迭代一步：设 w = 2.5 处导数为 +4，则 w := 2.5 − 0.1 × 4 = 2.5 − 0.4 = 2.1（继续向左，且步长变小）。两次更新都在向谷底逼近，坡度越缓步长越小。

**为什么必须「同时更新」**：∂J/∂w 与 ∂J/∂b 都依赖当前的 w、b。若先更新 w、再用新 w 算 ∂J/∂b，第二步就沿了错误方向，容易走弯路、震荡甚至发散。必须先算完所有偏导，再一次全部赋值。

**常见误区/注意点**：
- 「:=」是赋值操作（覆盖旧值），不是数学上的「等于」；
- 严禁逐个更新参数，必须同时更新；
- 每步位移 = α × |偏导|，坡度越陡走得越快、越缓走得越慢。

## 学习率 α

**定义**：学习率 α 是控制每步位移量的正数缩放因子，梯度乘以 α 才是本步真正移动的距离。

**公式**：更新式 w := w − α·∂J/∂w 中，α 是步长缩放因子，∂J/∂w 是坡度方向；本步实际位移量 = α × |∂J/∂w|。

**表现对照**：
- 过小：每步只挪一点点，J 缓慢下降，最终能收敛但耗时极长、浪费算力；
- 合适：J 每轮稳定下降，几步后明显变小，收敛快且稳定；
- 过大：一步跨过谷底冲到对侧来回震荡，J 不降反升甚至发散。

**实例（数字演算）**：设 J(w) = 2w²，∂J/∂w = 4w，从 w = 1 出发（此时 ∂J/∂w = 4），比较 α = 0.1 与 α = 3。

α = 0.1（合适）：
```
第 1 轮：w = 1 − 0.1×4 = 0.6         （J：2 → 0.72）
第 2 轮：w = 0.6 − 0.1×2.4 = 0.36     （J：0.72 → 0.26）
第 3 轮：w = 0.36 − 0.1×1.44 = 0.216  （J：0.26 → 0.09）
```
J 一路下降，稳步逼近谷底 w = 0。

α = 3（过大）：
```
第 1 轮：w = 1 − 3×4 = −11            （一步跨过谷底 0 冲到对侧，J 跳到 242）
第 2 轮：w = −11 − 3×(−44) = 121      （再次跨过谷底，J 跳到 29282）
第 3 轮：w = 121 − 3×484 = −1331      （越冲越远，J 爆炸到 3543122）
```
因为步长 12 远大于起点到谷底的距离 1，w 每次都越过谷底且越跳越远——这就是「大学习率跨过谷底后发散」。

**如何用 J 曲线判断收敛**：每轮迭代后记录 J(w, b)，画出 J 随迭代次数变化的曲线：
- 曲线单调下降并趋于水平 → α 合适，已收敛；
- 曲线震荡或上升 → α 过大，应调小；
- 曲线下降但极缓慢 → α 过小，可调大加速。
当相邻两轮 J 的变化小到可忽略（如 < 10⁻³）即认为收敛，可停止迭代。

**常见误区/注意点**：
- 判断收敛要看 **J 是否趋于平稳**，而不是看 w、b 的数值或梯度绝对值；
- α 需手工试参，常见从 0.01、0.03、0.1、0.3 按约 3 倍间隔尝试；
- 可配合「学习率衰减」：前期大步快走，后期逐步缩小步长保证稳定。

## 用于线性回归

**定义**：把梯度下降套用到线性回归的平方误差代价函数上，得到可直接迭代的批量梯度下降公式。模型 f(x) = wx + b，代价函数 J(w, b) = (1/(2m))·Σᵢ(f(x⁽ⁱ⁾) − y⁽ⁱ⁾)²，其中 m 为样本数。

**推导（对 w、b 求偏导的中间步骤）**：
```
∂J/∂w = ∂/∂w [ (1/(2m)) Σ (w·x⁽ⁱ⁾ + b − y⁽ⁱ⁾)² ]
       = (1/(2m)) Σ 2(w·x⁽ⁱ⁾ + b − y⁽ⁱ⁾) · x⁽ⁱ⁾   ← 链式法则，内层对 w 求导得 x⁽ⁱ⁾
       = (1/m) Σ ( f(x⁽ⁱ⁾) − y⁽ⁱ⁾ ) · x⁽ⁱ⁾         ← 2 与 1/2 约掉
∂J/∂b = (1/(2m)) Σ 2(w·x⁽ⁱ⁾ + b − y⁽ⁱ⁾) · 1       ← 内层对 b 求导得 1
       = (1/m) Σ ( f(x⁽ⁱ⁾) − y⁽ⁱ⁾ )
```
每个样本的贡献是「误差 × 该样本的特征值」：误差越大的样本被修正得越狠，特征值越大的样本其权重被修正得越猛。

**伪代码（批量梯度下降）**：
```
重复直到收敛：
    ∂J/∂w := (1/m) Σᵢ ( f(x⁽ⁱ⁾) − y⁽ⁱ⁾ ) · x⁽ⁱ⁾
    ∂J/∂b := (1/m) Σᵢ ( f(x⁽ⁱ⁾) − y⁽ⁱ⁾ )
    w := w − α · ∂J/∂w
    b := b − α · ∂J/∂b
```
每一步都用**全部训练样本**计算梯度，故称「批量梯度下降（Batch Gradient Descent）」。

**实例（3 个样本，完整手算 2 轮）**：训练集 (x, y) = (1,1)、(2,2)、(3,3)，初始 w = 0、b = 0，α = 0.1。

第 1 轮：
```
预测：f(1) = 0，f(2) = 0，f(3) = 0
误差：f − y = −1、−2、−3
∂J/∂w = (1/3)[(−1)(1) + (−2)(2) + (−3)(3)]
       = (1/3)(−1 − 4 − 9) = −14/3 ≈ −4.67
∂J/∂b = (1/3)(−1 − 2 − 3) = −6/3 = −2
更新：w = 0 − 0.1×(−4.67) = 0.467
      b = 0 − 0.1×(−2) = 0.2
J = (1/6)[(−1)² + (−2)² + (−3)²] = 14/6 ≈ 2.33
```

第 2 轮：
```
预测：f(1) = 0.467×1 + 0.2 = 0.667
      f(2) = 0.467×2 + 0.2 = 1.134
      f(3) = 0.467×3 + 0.2 = 1.601
误差：f − y = −0.333、−0.866、−1.399
∂J/∂w = (1/3)[(−0.333)(1) + (−0.866)(2) + (−1.399)(3)]
       = (1/3)(−0.333 − 1.732 − 4.197) = −6.262/3 ≈ −2.09
∂J/∂b = (1/3)(−0.333 − 0.866 − 1.399) = −2.598/3 ≈ −0.87
更新：w = 0.467 − 0.1×(−2.09) = 0.676
      b = 0.2 − 0.1×(−0.87) = 0.287
J = (1/6)(0.333² + 0.866² + 1.399²) = (1/6)(0.111 + 0.750 + 1.957) ≈ 2.818/6 ≈ 0.47
```
两轮后 J 从 2.33 降到 0.47，w、b 从 0 开始向真实模型（w = 1, b = 0）逐步逼近，说明梯度下降在朝正确方向修正。

**常见误区/注意点**：
- 多特征时每个 wⱼ 独立按 ∂J/∂wⱼ = (1/m)Σ(f − y)·xⱼ 更新，模式完全相同；
- 误差写成 (y − f) 会使偏导变号，但收敛方向等价，公式中务必保持符号一致；
- 系数 (1/2m) 中的 2 是为让求导结果整洁而刻意设计的，推导时勿忘约分；
- 批量梯度下降每轮扫一遍全部样本，样本量巨大时开销高，可改用随机/小批量变体。

## 特征缩放

**定义**：特征缩放（Feature Scaling）是把每个特征的取值变换到相近的数量级（通常约为 −1 到 1），使梯度下降收敛更快、更稳。

**为什么量级差异大会导致收敛慢**：若面积取值 0~2000、卧室数取值 0~5，量级相差 400 倍，代价函数的等高线被拉成狭长椭圆，梯度方向与椭圆短轴近乎垂直，每一步都在「横穿」椭圆、左右折返：
```
缩放前：狭长椭圆等高线，路径锯齿状折返，收敛极慢：
   卧室
   5 │    ╭───────────╮
   3 │   ╱             ╲
   2 │  │   ↗ ↖ ↗ ↖    │
   1 │   ╲             ╱
   0 │    ╰───────────╯
     └────────────────────→ 面积
```
缩放后：等高线接近正圆，梯度方向直指圆心，路径近似直线，几步即可收敛：
```
   卧室'
    │       ○
    │      ○ ○
    │     ○  ·  ○
    │      ○ ○
    │       ○
    └──────────────→ 面积'
```

**标准化公式**：
```
x_scaled = (x − μ) / σ
```

**符号表**：

| 符号       | 含义                      |
| -------- | ----------------------- |
| x        | 某样本在该特征上的原始取值           |
| μ        | 该特征在所有样本上的均值            |
| σ        | 该特征的标准差（也可用最大值 − 最小值代替） |
| x_scaled | 缩放后的取值，量级约在 −1 到 1 之间   |

**实例（手算）**：简化训练集（面积, 卧室）= (500, 0) 与 (2000, 5)。
```
面积 x₁：μ₁ = (500 + 2000)/2 = 1250，σ₁ = |2000 − 500|/2 = 750
卧室 x₂：μ₂ = (0 + 5)/2 = 2.5，σ₂ = (5 − 0)/2 = 2.5
缩放样本 (500, 0)：x₁_scaled = (500 − 1250)/750 = −1；x₂_scaled = (0 − 2.5)/2.5 = −1
缩放样本 (2000, 5)：x₁_scaled = (2000 − 1250)/750 = 1；x₂_scaled = (5 − 2.5)/2.5 = 1
```
两个样本的两个特征都被映射到 [−1, 1]，量级完全一致，梯度下降可以「走直线」直达谷底。

**多项式特征更需缩放**：多项式模型 f(x) = w₁x + w₂x² + w₃x³ + b 只是把 x、x²、x³ 当作三个普通特征，梯度下降公式不变；但若 x ∈ [1, 1000]，则 x³ ∈ [1, 10⁹]，量级差达 9 个数量级，不缩放几乎无法收敛，因此多项式回归中特征缩放是**前提条件**。

**判断是否需要缩放**：若某特征的取值范围比其他特征大 3 个数量级以上，或特征以 x²、x³ 等形式组合，就必须缩放。

**常见误区/注意点**：
- 缩放要用**训练集**算出的 μ、σ；预测新样本时沿用同一组 μ、σ，不要重新计算；
- σ 用标准差或极差均可，但整个流程中必须保持一致；
- 缩放只改变特征的数值尺度，不改变模型含义与预测结果。

## 卡片：易错点

| 要点        | 说明                                      |
| --------- | --------------------------------------- |
| 同时更新      | w 和 b 必须用旧参数一起算完再统一赋值，不能逐个更新            |
| 学习率不是越小越好 | 太小收敛慢、太大发散；用 J 的下降趋势判断是否合适              |
| 用 J 判断收敛  | 看代价函数是否趋于平稳，而不是看参数或梯度的绝对值               |
| 特征缩放是前提   | 多特征/多项式特征不缩放，梯度下降会极慢甚至发散                |
| 局部最优      | 非凸问题可能陷入局部最优；线性回归是凸函数，无此顾虑              |
| 负梯度方向     | 更新式是 θ := θ − α·∂J/∂θ，减号不能丢，丢了会朝上坡走     |
| 方向与步长分离   | 移动方向由梯度的符号决定，移动距离由 α × \|梯度\| 决定，两者不能混用 |
| 迭代终止条件    | 提前终止会欠拟合，无限迭代纯属浪费；用 J 的变化量设定停止条件        |
